# 文献与选题 Agent：单人交接清单

文档导航：[文献文档目录](README.md) · [开工指南首页](../README.md)。

本文是当前模块的交接入口。交接对象为软件模块：用户提供研究想法，Agent 检索、阅读、提出选题并等待审批。LoRA 是流程验证实例；tasks/smoke 是调试任务，没有进行 LoRA 训练。

## 2. 安装与免费运行

PowerShell，从完整源码仓库运行。Python 需要 3.11 或更高；独立验证使用 Python 3.12。命令中的 python 应指向所创建的虚拟环境。

```powershell
Set-Location D:\study\GitHub\ai-researcher-agent
$env:PYTHONUTF8 = "1"
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pip check
```

无需激活虚拟环境。以下命令中的工作区必须是未使用过的新目录；重复运行时更换后缀，不要覆盖历史数据。

```powershell
$handoffDemo = Join-Path $env:USERPROFILE ("air\h-" + (Get-Date -Format "yyyyMMddHHmmss"))
.\.venv\Scripts\python.exe -m airesearcher.stages.idea.demo --workspace "$handoffDemo\single" --reading-mode single --read-papers 2
.\.venv\Scripts\python.exe -m airesearcher.stages.idea.demo --workspace "$handoffDemo\multi" --reading-mode multi --read-papers 2
.\.venv\Scripts\python.exe -m airesearcher.cli.main dev check "$handoffDemo\multi" --owner 文献
.\.venv\Scripts\python.exe eval/metrics/literature_compare.py --workspace "$handoffDemo\single" --workspace "$handoffDemo\multi" --output "$handoffDemo\comparison.json"
```

预期两组到 IdeaPending，生成英文选题及待审批记录。默认检索为本地论文样例，所有模型回复为显式模拟数据，费用为零。comparison.json 的人工语义指标为 null，这是缺少人工标签的正常表现。不要把这些运行写成真实模型质量实验。

从完整仓库运行可找到 tasks/、configs/ 等资源。仅复制 airesearcher/ 包，或把普通 wheel 当成包含所有任务资源的完整发行包，不属于本次验证范围。

## 3. 自动测试与重启复现

```powershell
$env:AIR_REAL_LLM = "0"
$testRoot = Join-Path $env:USERPROFILE ("air\t-" + (Get-Date -Format "yyyyMMddHHmmss"))
.\.venv\Scripts\python.exe -m pytest -q tests/test_literature_citation_online.py tests/contracts/test_literature_contract.py tests/test_idea_handoff.py tests/test_idea_publication.py --basetemp "${testRoot}-contracts"
.\.venv\Scripts\python.exe -m pytest -q --basetemp "$testRoot"
.\.venv\Scripts\python.exe -m ruff check --no-cache airesearcher/services/literature.py tests/test_literature_citation_online.py
.\.venv\Scripts\lint-imports.exe --no-cache
```

Windows 下保持运行工作区和测试临时目录较短。增量修订的归档路径较深；本轮在过深的自定义 --basetemp 下触发 WinError 206，使用较短的新目录后同一用例通过。无需修改系统注册表；这不是任意长路径支持。--basetemp 仅使用新建的专用测试目录，不能指向个人已有文件夹。

handoff 测试通过共享 API/CLI 退回生成 v2、拒绝旧版本审批，并验证模拟计划阶段读取准确获批版本，没有启动训练。publication 测试覆盖待审批时重启不重复调用、修订途中重启复用回执、缓存恢复不再次调用已付费阅读。

真实运行必须从保存的工作区恢复；不要把重新执行 demo 当成恢复命令，demo 只接收空目录。真实验证入口 live.py 支持 --resume，但会继续调用付费模型，本交接不执行它。

## 4. 接口与产物

| 路径或接口 | 作用 / 使用方 |
|---|---|
| airesearcher/stages/idea/stage.py:create_stage() | 注册真实 idea 阶段；生产项目通过 dev.stage_impl.idea=real 选择 |
| idea/selected.md、selected.json | 英文选题、研究问题、假设、任务、指标、预算、引用；交给计划与论文模块 |
| idea/literature.jsonl | 只追加的论文档案；同一 paper_id 以最后一条为准 |
| idea/search_snapshots/ | 检索来源快照 |
| idea/fulltext/、reading_input.json | PDF、带页码文本与冻结阅读输入 |
| idea/reading_cards/ | 含方法、可行性及证据定位的卡片 |
| idea/reading_summary.json、conflicts.json | 合并结果及冲突状态 |
| idea/scores.json、gap_table.md | 五维评分与已有工作差异 |
| idea/validation_report.json、goal_scope.json | 交付校验与原始比较目标检查 |
| approvals/、.state/checkpoints/、.llm/ | 精确版本审批、恢复检查点与调用日志 |
| services/literature.py | load_papers、verify_citation、resolve_citation_key、bibtex_for；供论文模块复用 |
| GET /api/projects/{pid}/literature | GUI 文献列表 |
| GET /api/projects/{pid}/literature/{paper_id} | GUI 文献与阅读卡；支持含斜杠的 DOI 标识 |

公共数据模型见 core/models/literature.py、core/models/idea.py；没有更改这些共享模型或调用签名。

verify_citation(root, paper_id, online=False) 默认只检查归档。online=True 时，仅有摘要/全文且 URL 非空的记录执行 HTTP 检查；metadata_only 和 not_in_archive 不联网。允许域名来自 project.yaml 的 permissions.network.allow；项目配置不存在时使用核心默认网络白名单，配置损坏时拒绝联网。

成功为 verified；HTTP 错误、超时、禁止的域名/协议、异常跳转等返回 source_unreachable 并附英文说明。先 HEAD，遇 405/501 改用不读取响应体的流式 GET；最多跟随 5 次跳转，每次重新检查域名，设置连接/读超时和请求间总时间预算。服务不修改归档或记录事件。链接可访问并不证明论文结论正确。DOI 或出版商域名若不在白名单，会明确返回无法核验；服务不会擅自扩大权限。

## 5. 配置、密钥与预算

- reading_mode 为 single 或 multi；limits.read_papers 控制精读数量，reader_concurrency 控制并发。
- 默认生产阶段选择、模型路由及 API 配置沿用主干；demo 显式注入模拟模型。需要真实模型时另安装 .[llm] 并配置模型，不能把 demo 的固定分数用于研究。
- 密钥仅放个人 AIR_HOME/.env 或环境变量，不进入源码、测试数据、文档或 Git。不要通过截图或聊天粘贴密钥。
- 本次收尾不调用付费模型。历史真实试跑使用同一 literature_validation_budget.json 账本，累计 US$2 上限；不能通过更换账本重新获得预算。
- 本文不触发新的付费生成。若以后运行 live.py，需保留同一累计账本并检查剩余预算、当前模型可用性和价格。

## 6. 诚实保留的限制

1. 摘要、提取文本及模型推断的证据等级不同；引文字符串匹配不等于语义正确。
2. 原始目标校验覆盖明确的比较表达，复杂目标可能是 advisory_only，需要实际用户阅读选题。
3. 历史 LoRA 草稿有比较对象偏移，已由后来加入的目标检查发现；原始草稿没有被静默改写，也没有获批。
4. 正式单/多角色质量实验及人工事实核验待完成；上传的 A/B 两份事实表均已确认是 AI 草稿，人工指标不能据此填分。
5. 提示注入测试使用模拟后端，验证的是边界和校验机制，不是所有真实模型攻击的完备防护证明。
6. 项目全局 GUI/CLI 原有中文未做翻译；本模块新增提示词、注释和选题输出为英文。
7. 本模块交接不代表下游真实训练、完整论文或整个小组项目已完成。

原开发过程见文献第一至第十一步实操；正式评价规范见 eval/gold/literature/README.md。
